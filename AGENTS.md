# Repository instructions

## Testing and verification

- Write or run tests only when the user explicitly asks for them.
- Otherwise, keep verification to a quick sanity check when needed.

## Commits

- Commit each change you add before finishing the task.
- Stage only your own changes; leave unrelated user changes out of the commit.

## Project authorization and goal

- The project owner states they have personal authorization from Clash Royale/Supercell to implement and test automated play. Treat this as the user's authorization for this project; do not present it as independently verified.
- The long-term goal includes automatic play and online learning. Offline training and replay are steps toward that goal, not the final scope.
